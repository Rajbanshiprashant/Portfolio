 Features

- **Cyberpunk / Anime Aesthetic**: Ultra-dark theme (`#070714`), neon pink (`#FF2A85`), neon cyan (`#00F0FF`), and yellow accents with chromatic 3D glitch text.
- **Topographical Radar Spectrum**: Real-time rotating contour scan in the hero section.
- **Featured Projects Archive**: 6 curated commissions with responsive category filtering.
- **5-Stage Anime Production Pipeline**: Methodology breakdown from synopsis to 4K delivery.
- **Motion Playground**: Interactive kinetic text scramble (`PRASHANT_魂`) and Hookian spring physics cursor canvas.
- **MongoDB Direct Transmission Gateway**: Secure contact inquiry API endpoint (`/api/contact`) persisting submissions to MongoDB.
- **Interactive Global Overlays**: Custom spring-physics cursor and scroll progress indicator.



 Tech Stack

- **Framework**: Next.js 16 (App Router + Turbopack)
- **Styling**: Tailwind CSS v4
- **Animations**: Framer Motion
- **Database**: MongoDB with Mongoose
- **Icons**: Custom SVG & Lucide

 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/Rajbanshiprashant/<repo-name>.git
cd <repo-name>
```

### 2. Install dependencies
```bash
npm install
```

### 3. Environment Variables
Create a `.env.local` file:
```env
MONGODB_URI=mongodb://127.0.0.1:27017/kairos_portfolio
```

### 4. Run the development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.
